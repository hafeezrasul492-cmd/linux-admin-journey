# Linux Systems Administration Portfolio

Hands-on labs, runbooks and automation projects built on AlmaLinux (RHEL-compatible).

## Contents
- `daily-log/`  Engineering log: tasks, commands, issues, resolutions
- `notes/`      Technical documentation by topic
- `labs/`       Scripts and lab exercises
- `runbooks/`   Operational procedures (disk full, service down, high load)
- `projects/`   End-to-end builds (secure web server, Ansible, AWS)

## Skills
Linux, SSH, firewalld, SELinux, LVM, Nginx, Bash, Ansible, Git
